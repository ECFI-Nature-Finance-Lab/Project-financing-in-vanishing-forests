# Project Finance in Vanishing Forests: Do investors care about nature protection?

## `deforestation_calculation`
iPython notebook containing script for retrieving Hansen et al. (2013) forest loss from Earth Engine. Requires access to Google Cloud.

## `wdpa_proximity_calculation`
iPython notebook for calculating proximity of project coordinates to World Database on Protected Areas (WDPA )polygons using native ArcGIS python functions. Requires ArcGIS Pro.

## `loan_pricing_analysis`
Stata script (`PF Code.do`) for running loan pricing analysis alongside input loan-pair data (`loan pair full sample.dta`).

## `equity_market_analysis`
iPython notebook (`Fig5_Event_Study.ipynb`) and data (described in notebook) for equity market event study.
